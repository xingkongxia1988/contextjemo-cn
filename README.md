# ContextJemo CN Site

contextjemo.cn 中文站。

- 根路径 `/` = 中文（.cn 域名的母语语言）
- `/en/` = 英文版
- 部署：GitHub Pages（`gh-pages` 分支），`CNAME` = `contextjemo.cn`

英文主站在 `xingkongxia1988/contextjemo-site`（根 = 英文，`/cn/` = 中文）。

## 设计约束（源自 design/creed.md）

1. 版面主体只用真实产物（AET YAML、内核红线、对比表）
2. 6 档字阶、10 档间距、1 个强调色（琥珀）
3. 宋体只在纸面段（`.sheet`）
4. 琥珀只出现在主 CTA 底色与 trace id 文字
